# Simple Interest Calculator

This project calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Description

The Simple Interest Calculator is a simple project that demonstrates the calculation of interest using a Bash script.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The time period in years.

## Usage

Run the `simple-interest.sh` script in a Bash-compatible terminal. Enter the principal amount, annual interest rate, and time period when prompted.

## Example

For a principal of 1000, an annual interest rate of 5%, and a time period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
